# Vessel Document Clearance System - Astro + React

A modern web application for vessel document clearance and cargo management built with Astro and React.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ installed
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/Moopraew/PraewQ88-Astro.git
cd PraewQ88-Astro

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:3000`

## 📦 Build for Production

```bash
npm run build
npm run preview
```

## 🏗️ Project Structure

```
src/
├── components/          # React components
│   ├── layout/         # Layout components

│   ├── admin/          # Admin screens

│   ├── modals/         # Modal components

├── pages/              # Astro pages
├── utils/              # Utility functions
```

## 🛠️ Technologies Used

- **Astro 4** - Modern static site builder
- **React 18** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first CSS framework
- **Font Awesome** - Icon library

## 📝 Features

- ✅ Dashboard with vessel request history

- ✅ Toast notifications

- ✅ Responsive design
- ✅ Dark/Light mode support

## 🎨 Customization

### Adding New Components

1. Create a new React component in `src/components/`
2. Import and use it in your pages
3. Style with Tailwind CSS classes

### Updating Tailwind Theme

Edit `tailwind.config.mjs` to customize colors, fonts, and spacing.
